# Study Time Tracker / Lernzeit-Tracker

Ein Python-Programm, um Lernzeiten zu erfassen und Ziele zu verfolgen.

A Python program to log study sessions and track goals.

-----------

## 🇩🇪 Deutsch (Einfach)

### Funktionen
1. **Session hinzufügen:** Fach und Dauer in Minuten eingeben.
2. **Gesamtzeit anzeigen:** Gesamte Lernzeit und Aufteilung nach Fächern sehen.
3. **Durchschnitt anzeigen:** Durchschnittliche tägliche Lernzeit berechnen (über 7 Tage).
4. **Ziel prüfen:** Ein Lernziel für ein Fach setzen und sehen, wie viel Zeit noch fehlt.
5. **Beenden:** Speichert alles automatisch in einer CSV-Datei (`study_log.csv`).

```bash
python3 project.py
